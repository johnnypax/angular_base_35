Creare un piccolo sistema di gestione CVE, ogni CVE è caratterizzata da almeno:

- Identificatore univoco
- Descrizione
- Data di scoperta
- Vettore

Utilizzare Angular Router per la gesitione di due pagine:

- Lista: Elenco delle CVE con un pulsante per eliminare una CVE dalla lista
- Inserimento: Attenzione alle CVE già presenti, non dovrebbe essere permesso l'inserimento di una CVE già esistente
